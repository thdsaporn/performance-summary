# เว็บไซต์งานการฝึกและวิชาการ กก.5 บก.กฝ.บช.ตชด.

ออนไลน์ที่ https://thdsaporn.github.io/performance-summary/ (GitHub Pages, branch `main`)

## หน้าในเว็บ
| ลิงก์ | ระบบ |
|---|---|
| `index.html` | หน้าสรุปผลการปฏิบัติงาน (หน้าหลัก) |
| `schedule.html` | ระบบตารางฝึกอบรม นสต. |
| `database.html` | ระบบฐานข้อมูลผู้สำเร็จการฝึกอบรม (เข้ารหัส ต้องใส่รหัสผ่านของหน่วย) |
| `field-training/` | ระบบประเมินผลฝึกปฏิบัติราชการ (`trainee/`, `mentor/`, `admin/`) |
| `ระบบคำนวณการฝึกหัดปฏิบัติราชการ_นสต..html` | เครื่องมือคำนวณคะแนนฝึกหัดปฏิบัติราชการ |

ไฟล์ชื่อภาษาไทยอื่น ๆ, `schedule/`, `database/`, `field-training.html` และ `field-training-*.html` เป็นหน้าเปลี่ยนทาง (redirect) สำหรับลิงก์เก่าเท่านั้น

## อัปเดตเว็บ
1. แก้ไฟล์ในโฟลเดอร์นี้
2. ฐานข้อมูล: แก้ไฟล์ต้นฉบับนอกโฟลเดอร์ deploy แล้วสร้าง `database.html` ใหม่ด้วย `เครื่องมือเข้ารหัสฐานข้อมูล.html` (ห้ามวางไฟล์ต้นฉบับที่ไม่เข้ารหัสไว้ที่นี่)
3. ดับเบิลคลิก `อัปขึ้นGitHub.bat`

`.gitignore` กันไม่ให้ไฟล์ .xlsx .docx .db .csv ขึ้น GitHub
