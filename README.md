# 🌐 คู่มือการนำระบบขึ้นออนไลน์ฟรี (Online Deployment Guide)

โฟลเดอร์ **deploy/** ได้รับการจัดเตรียมโครงสร้างไฟล์ไว้สมบูรณ์แบบ 100% รวม **๓ ระบบหลัก** ไว้ในแพ็กเกจเดียว พร้อมนำขึ้นออนไลน์ได้ทันที:

1. **หน้าพอร์ทัลนำเสนอผลงาน (Main Portal):** index.html
2. **ระบบตารางฝึกอบรม นสต.:** ระบบตารางฝึกอบรม_นสต..html (หรือ /schedule)
3. **ระบบฐานข้อมูลผู้สำเร็จการฝึกอบรม (๒,๓๒๕ นาย):** ระบบฐานข้อมูลผู้สำเร็จการฝึกอบรม.html (หรือ /database)

---

## 🚀 วิธีที่ ๑ : Netlify Drop (ง่ายและเร็วที่สุด — ได้เว็บใน ๑๐ วินาที)

1. เปิดเบราว์เซอร์ไปที่: **https://app.netlify.com/drop**
2. เปิดโฟลเดอร์ **ระบบตารางสอน** ในเครื่องของท่าน
3. **ลากโฟลเดอร์ deploy ทั้งโฟลเดอร์** ไปปล่อยลงในกรอบสี่เหลี่ยมบนหน้าเว็บ Netlify Drop
4. รอระบบอัปโหลด 3–5 วินาที จะได้ **URL เว็บไซต์ออนไลน์ทันที** เช่น:
   - https://pol-training-กก5.netlify.app
5. สามารถนำลิงก์นี้ไป:
   - เปิดดูบนสมาร์ทโฟน / แท็บเล็ต
   - ส่งให้ผู้บังคับบัญชาหรือกรรมการตรวจประเมิน
   - สร้าง QR Code แปะในเอกสารนำเสนอ

*(แนะนำ: หากล็อกอิน Netlify ฟรีด้วยอีเมล ลิงก์จะอยู่ถาวรตลอดไป และสามารถเปลี่ยนชื่อ URL ให้สวยงามได้ตามต้องการ)*

---

## 🐙 วิธีที่ ๒ : GitHub Pages (เป็นทางการสำหรับหน่วยงาน)

1. เข้าสู่ระบบ https://github.com
2. สร้าง Repository ใหม่ เช่น police-training-system (ตั้งเป็น Public)
3. อัปโหลดไฟล์ทั้งหมดที่อยู่ในโฟลเดอร์ **deploy** ขึ้นไปที่ Repository
4. ไปที่ **Settings** ➔ เมนูด้านซ้ายเลือก **Pages**
5. ในส่วน **Branch** เลือก main หรือ master ➔ กด **Save**
6. ภายใน 1–2 นาที จะได้รับลิงก์เว็บทางการ:
   - https://[ชื่อผู้ใช้].github.io/police-training-system/

---

## ⚡ วิธีที่ ๓ : Vercel (เร็วและทันสมัย)

1. เปิดเว็บ https://vercel.com
2. ล็อกอินแล้วกด **Add New...** ➔ **Project**
3. ลากโฟลเดอร์ deploy ขึ้นไป หรือเชื่อมต่อกับ GitHub
4. กด **Deploy** ➔ ได้ลิงก์ .vercel.app ทันที

---

## 💻 วิธีที่ ๔ : สาธิตในวงแลน / Wi-Fi หน่วยงาน (ไม่ต้องต่อเน็ต)

หากต้องการเปิดให้คนในห้องประชุมที่ต่อ Wi-Fi เดียวกันเข้าใช้งาน:
1. เปิด PowerShell ในโฟลเดอร์ deploy
2. พิมพ์คำสั่ง:
   `ash
   python -m http.server 8080
   `
3. ทุกคนในวง Wi-Fi สามารถพิมพ์ http://[IP_เครื่องท่าน]:8080 เพื่อเข้าใช้งานได้ทันทีครับ
