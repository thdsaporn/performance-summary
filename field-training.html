ระบบบริหารและประเมินผลการฝึกหัดปฏิบัติราชการ นสต.

ระบบบันทึกรายวัน · ครูพี่เลี้ยงประเมินผล · คำนวณคะแนน บช.ศ. (๑,๑๖๐ คะแนน) · กก.๕ บก.กฝ.บช.ตชด.

เลือกระบบงานที่ต้องการเข้าใช้งาน (๓ พอร์ทัลเฉพาะทาง)

เข้าใช้งานตามบทบาทหน้าที่ของท่าน เพื่อการบันทึก ประเมินผล และสรุปคะแนนที่ถูกต้อง

📝
๑. สำหรับ นสต. (ผู้รับการฝึก)
ระบบลงบันทึกเหตุการณ์และการปฏิบัติงานประจำวันสำหรับนักเรียนนายสิบตำรวจ
  • ✓ เลือกหัวข้อการปฏิบัติงาน (๒.๑ – ๒.๑๔)
  • ✓ พิมพ์บันทึกการปฏิบัติงานประจำวัน (ส่วนที่ ๒)
  • ✓ ติดตามผลการตรวจและคำแนะนำของครูพี่เลี้ยง
เข้าสู่พอร์ทัล นสต. ➔
👨‍✈️
๒. สำหรับ ครูพี่เลี้ยง (ผู้ควบคุมการฝึก)
ระบบตรวจประเมินผลรายวัน ออกแบบประเมินรายเดือน (แบบที่ ๒) และแบบสรุปผล (แบบที่ ๓)
  • ✓ ตรวจประเมิน ๓ ส่วน (ความพร้อม/ปฏิบัติงาน/หลังปฏิบัติ)
  • ✓ ให้ข้อเสนอแนะและคำแนะนำประจำวันแก่ นสต.
  • ✓ พิมพ์แบบประเมินรายเดือน (แบบที่ ๒) และแบบสรุปผล (แบบที่ ๓)
เข้าสู่พอร์ทัล ครูพี่เลี้ยง ➔
📊
๓. สำหรับ งานการฝึกและวิชาการ
ระบบสรุปผลและคำนวณคะแนนตามสูตร บช.ศ. (๑,๑๖๐ คะแนน) ดูรายคน และจัดอันดับทั้งรุ่น
  • ✓ คำนวณคะแนนภาค ๑ (๓๔๐), ภาค ๒ (๘๒๐), รวม ๑,๑๖๐
  • ✓ คิดค่าน้ำหนัก ๑๐% (๓๘๗ คะแนน) สำหรับจัดลำดับเลือกตำแหน่ง
  • ✓ ดูรายบุคคล / ดูทุกคนทั้งรุ่น (Ranking) และพิมพ์รายงานส่ง บช.ศ.
เข้าสู่พอร์ทัล งานการฝึกและวิชาการ (สรุปคะแนน) ➔
🏠 กลับหน้าหลักพอร์ตผลงาน
กองกำกับการ ๕ กองบังคับการฝึกพิเศษ กองบัญชาการตำรวจตระเวนชายแดน (ค่ายนเรศวรมหาราช)
